# Fake SpeedTest Server

Приватный HTTP-сервер для тестирования скорости сети (аналог speedtest.net). Эмулирует загрузку файлов различных размеров для проверки пропускной способности канала.

## Особенности

- **Генерация фейковых файлов**: 100 МБ, 200 МБ, 500 МБ, 1000 МБ
- **Защита от сканирования**: жёсткий бан за один неправильный запрос
- **Перманентный бан**: блокировка на 200 000 лет за подозрительную активность
- **Ночной режим**: автоматическая пауза работы в заданные часы
- **Секретный код разбана**: `748_dark` для экстренного доступа
- **Логирование**: запись всех событий в файлы с временными метками
- **Рандомные заголовки**: имитация различных серверов через `X-Powered-By`

## Требования

- **.NET Framework 4.8**
- **Windows Server 2008 R2 SP1** или новее
- Права администратора (для запуска на порту 5000)

## Запуск

```bash
# Сборка
msbuild "fake server speedtest.csproj" /p:Configuration=Release

# Запуск
FakeDownloadServer.exe
```

Сервер доступен по адресу: `http://localhost:5000/`

## Конфигурация

### Ночной режим
Включён по умолчанию с 01:00 до 06:00. Для изменения отредактируйте в `Program.cs`:
```csharp
private static int nightStartHour = 1;  // Начало
private static int nightEndHour = 6;    // Конец
private static bool isNightModeEnabled = true;
```

Для принудительного запуска в ночное время нажмите **Y** в консоли.

### Белый список
Разрешённые пути (остальные приводят к бану):
- `/` — главная страница
- `/favicon.ico`
- `/download/100`, `/download/200`, `/download/500`, `/download/1000`
- `/748_dark` — секретный путь для разбана

### Файл ban.ini
Хранит забаненные IP-адреса и сроки блокировки в формате:
```
IP_адрес|YYYY-MM-DD HH:mm:ss
```

### Файл random_headers.txt
Список заголовков для рандомизации `X-Powered-By`. Каждая строка — отдельный заголовок.

## Детектирование подозрительных запросов

Бан накладывается при наличии следующих признаков:
- User-Agent содержит: `curl`, `wget`, `python`, `scanner`, `bot`, `spider`, `crawler`
- Пустой User-Agent
- Заголовок `Accept: */*` без `Accept-Language`
- Запрос пути вне белого списка (достаточно 1 раза)

## Логи

Формат имени файла логов: `server_log_YYYY-MM-DD_HH-mm-ss.txt`

Логи содержат:
- Время события
- IP-адрес клиента
- Тип запроса
- Статус операции
- Скорость загрузки (Mbit/s)

## Секретный код разбана

Если вы забанили себя, добавьте `748_dark` к запросу:
- URL: `http://server:5000/748_dark`
- Query: `http://server:5000/?748_dark`
- User-Agent: любой, содержащий `748_dark`

Это автоматически разбанит ваш IP и перезапустит сервер.

## Примечания

- Проект приватный, для личного использования
- HTTPS не поддерживается (планируется в будущих версиях)
- Агрессивная политика безопасности — особенность дизайна
- Оскорбительный контент в `random_headers.txt` намеренный
- **Ночной режим**: исправлена потокобезопасность, убрано дублирование логики

## Изменения в последнем обновлении

### Исправление ночного режима
- Убрано дублирование проверки времени между `Main()` и `CheckNightModeAsync()`

- Переименовано `forceRunAtNight` → `isForceRunRequested` для ясности
- Удалён неиспользуемый метод `WaitForDayTime()`
- Основной цикл больше не крутится вхолостую при ночном режиме
- Убрана гонка данных при чтении консоли из разных потоков
