# ТЕХНИЧЕСКОЕ ЗАДАНИЕ
## на разработку приватного HTTP-сервера для тестирования скорости сети (Fake SpeedTest Server)

---

## 1. ОБЩИЕ СВЕДЕНИЯ

### 1.1. Наименование проекта
**Fake SpeedTest Server** — приватный HTTP-сервер для эмуляции загрузки файлов различных размеров с целью тестирования пропускной способности сетевого канала.

### 1.2. Область применения
Проект предназначен для личного использования в закрытых сетях. Сервер имитирует публичные сервисы измерения скорости (аналог speedtest.net), предоставляя возможность загрузки фейковых файлов размером от 1 МБ до 10 ГБ.

### 1.3. Термины и определения
| Термин | Определение |
|--------|-------------|
| **Ночной режим** | Автоматическая пауза работы сервера в заданные часы |
| **Бан** | Блокировка IP-адреса клиента на определённый срок |
| **Перманентный бан** | Блокировка IP-адреса на 200 000 лет |
| **Секретный код разбана** | Специальная комбинация `748_dark` для экстренного снятия блокировки |
| **Белый список** | Перечень разрешённых URL-путей для доступа |
| **Подозрительный User-Agent** | Строка заголовка, указывающая на автоматизированный инструмент |

## 3. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

### 3.1. Генерация файлов для скачивания
Сервер должен поддерживать генерацию фейковых файлов следующих размеров:

| Размер (МБ) | URL-эндпоинт |
|-------------|--------------|
| 100 | `/download/100` |
| 200 | `/download/200` |
| 500 | `/download/500` |
| 1000 | `/download/1000` |
| N (1–10240) | `/download/N` |

**Требования к генерации:**
- Файлы генерируются «на лету» без сохранения на диск
- Начало файла содержит маркер: `ТЕСТ` (UTF-8)
- Конец файла содержит маркер: `ТЕСТ` (UTF-8)
- Остальное содержимое — нулевые байты
- Заголовок `Content-Disposition` должен содержать имя файла
- Поддержка потоковой передачи с размером буфера 1 МБ

### 3.2. Система безопасности и банов

#### 3.2.1. Белый список URL
Разрешённые пути (доступ без ограничений):
- `/` — главная страница с интерфейсом
- `/favicon.ico` — иконка сайта
- `/updateBrowserInfo` — эндпоинт для обновления информации о браузере
- `/748_dark` — секретный путь для разбана
- `/download/N` — где N число от 1 до 10240

#### 3.2.2. Детектирование подозрительных запросов
Бан накладывается при наличии любого из признаков:

| Признак | Описание | Срок бана |
|---------|----------|-----------|
| Подозрительный User-Agent | Содержит ключевые слова из `suspicious_agents.txt` | 200 000 лет |
| Пустой User-Agent | Отсутствует заголовок User-Agent | 200 000 лет |
| Accept: */* без Accept-Language | Нестандартный набор заголовков | 200 000 лет |
| Запрос вне белого списка | Любой неизвестный путь | 2 минуты (после 1 попытки) |

#### 3.2.3. Список подозрительных User-Agent
По умолчанию включает (регистронезависимый поиск):
```
curl, wget, python, scanner, bot, spider, crawler, zgrab, 
go-http-client, internetmeasurement, palo alto networks, 
masscan, nmap, nikto, sqlmap
```

#### 3.2.4. Механизм перманентного бана
- Срок блокировки: **200 000 лет**
- Файл хранения: `bans.ini`
- Формат записи: `IP_адрес|YYYY-MM-DD HH:mm:ss`
- Проверка срока действия при каждом запросе

#### 3.2.5. Секретный код разбана
Код `748_dark` может быть передан:
- В URL: `http://server:5000/748_dark`
- В Query String: `http://server:5000/?748_dark`
- В User-Agent: любой, содержащий `748_dark`

**Действия при обнаружении кода:**
1. Мгновенный разбан IP-адреса
2. Отправка редиректа (302) на главную страницу
3. Перезапуск приложения
4. Логирование события

### 3.3. Ночной режим работы

#### 3.3.1. Параметры ночного режима
| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| `nightStartHour` | 1 (01:00) | Время начала |
| `nightEndHour` | 6 (06:00) | Время окончания |
| `isNightModeEnabled` | true | Включён по умолчанию |

#### 3.3.2. Поведение в ночном режиме
- Основной цикл переходит в режим ожидания
- Обработка запросов приостанавливается
- Вывод сообщения в консоль о статусе
- Проверка каждые 1 секунду

#### 3.3.3. Принудительный запуск
- Пользователь может нажать клавишу **'Y'** в консоли
- Флаг `isForceRunRequested` устанавливается в `true`
- Сервер возобновляет работу до конца ночного периода
- Сброс флага происходит автоматически при наступлении дневного времени

#### 3.3.4. Потокобезопасность
- Использование блокировки `nightModeLock` для всех операций с флагами
- Переменные объявлены как `volatile`
- Отдельный поток для проверки ночного режима
- Асинхронное ожидание с `CancellationToken`

### 3.4. Логирование

#### 3.4.1. Файлы логов
- Формат имени: `server_log_YYYY-MM-DD_HH-mm-ss.txt`
- Кодировка: UTF-8
- Создание нового файла при каждом запуске

#### 3.4.2. Содержимое логов
Каждая запись должна содержать:
- Временную метку
- IP-адрес клиента
- Тип запроса (URL, метод)
- Статус операции (успех/ошибка)
- Скорость загрузки (Mbit/s) для успешных скачиваний
- События системы банов

#### 3.4.3. Синхронизация
- Использование блокировки `logLock` для потокобезопасной записи
- Буферизация вывода в консоль и файл

### 3.5. Рандомизация заголовков

#### 3.5.1. Файл random_headers.txt
- Каждая строка — отдельный заголовок
- Загружается при старте сервера
- Пустые строки игнорируются

#### 3.5.2. Заголовок X-Powered-By
- Выбирается случайным образом из загруженного списка
- Добавляется к каждому ответу сервера
- Потокобезопасный доступ через `headerLock`

### 3.6. Мониторинг файла suspicious_agents.txt

#### 3.6.1. FileSystemWatcher
- Автоматическое отслеживание изменений файла
- Горячая перезагрузка списка без рестарта сервера
- Задержка 100 мс перед чтением (для завершения записи)

#### 3.6.2. Формат файла
- Ключевые слова или фразы (по одной в строке)
- Комментарии начинаются с `#`
- Пустые строки игнорируются
- Поиск регистронезависимый

## 4. АРХИТЕКТУРА СИСТЕМЫ

### 4.1. Компоненты системы

```
┌─────────────────────────────────────────────────────────┐
│                    Main Loop                            │
│  - Проверка isInSleepMode                               │
│  - Ожидание запросов (HttpListener.GetContextAsync)     │
└───────────────────────┬─────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────┐
│              CheckNightModeAsync (отдельный поток)      │
│  - Периодическая проверка IsNightTime()                 │
│  - Управление флагами nightMode                         │
│  - Очистка старых записей tracking (каждую минуту)      │
└───────────────────────┬─────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────┐
│              HandleRequestAsync (асинхронно)            │
│  - Проверка бана IP                                     │
│  - Детектирование подозрительных запросов               │
│  - Валидация белого списка                              │
│  - Обработка секретного кода разбана                    │
│  - Вызов ProcessRequestNormally                         │
└───────────────────────┬─────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────┐
│                   BanManager                            │
│  - Работа с bans.ini                                    │
│  - Отслеживание активности клиентов                     │
│  - CleanupOldTracking                                   │
└─────────────────────────────────────────────────────────┘
```

### 4.2. Классы и структуры

#### 4.2.1. Program (основной класс)
**Статические поля:**
- `nightModeLock` — объект блокировки для ночного режима
- `isInSleepMode` — флаг спящего режима (volatile)
- `isForceRunRequested` — флаг принудительного запуска (volatile)
- `isNightModeEnabled` — флаг включения ночного режима (volatile)
- `nightStartHour`, `nightEndHour` — часы ночного режима
- `MinFileSizeMB`, `MaxFileSizeMB` — ограничения размера (1–10240 МБ)
- `WhiteListedPaths` — массив разрешённых путей
- `banManager` — экземпляр менеджера банов
- `randomHeaders` — список заголовков для рандомизации
- `suspiciousUserAgents` — список подозрительных агентов
- `fileWatcher` — наблюдатель за файлом agents
- `serverCts` — токен отмены сервера
- `listener` — HttpListener

**Основные методы:**
- `Main()` — точка входа, инициализация и основной цикл
- `IsNightTime()` — проверка текущего времени
- `WaitForDayTime()` — ожидание дневного времени
- `HandleRequestAsync()` — обработка входящих запросов
- `ProcessRequestNormally()` — нормальная обработка запроса
- `StreamFakeFileAsync()` — потоковая передача файла
- `IsSuspiciousRequest()` — проверка на подозрительность
- `LoadSuspiciousUserAgents()` — загрузка списка агентов
- `InitializeFileWatcher()` — инициализация наблюдателя
- `Log()`, `LogErrorToFile()` — функции логирования

#### 4.2.2. BanManager
**Поля:**
- `_banFile` — путь к файлу банов
- `_bannedClients` — словарь IP → DateTime окончания бана
- `_clientTracking` — словарь IP → ClientTracking
- `_lock` — объект блокировки

**Методы:**
- `IsBanned(ip)` — проверка статуса бана
- `BanClient(ip, duration)` — установка бана
- `UnbanClient(ip)` — снятие бана
- `GetOrCreateClientTracking(ip)` — получение трекера
- `CleanupOldTracking(maxAgeMinutes)` — очистка старых записей
- `LoadBans()`, `SaveBans()` — работа с файлом

#### 4.2.3. ClientTracking
**Поля:**
- `BadRequestCount` — счётчик недопустимых запросов
- `FullBrowserVersion` — полная версия браузера
- `ClientBrowserName` — имя браузера

### 4.3. Диаграмма последовательности обработки запроса

```
Клиент          →    HttpListener    →    HandleRequestAsync
   │                       │                      │
   │─── Request ──────────►│                      │
   │                       │─── GetContextAsync ─►│
   │                       │                      │
   │                       │                      ├──► IsBanned()
   │                       │                      ├──► IsSuspiciousRequest()
   │                       │                      ├──► IsWhiteListed()
   │                       │                      │
   │                       │                      ▼
   │                       │              ProcessRequestNormally()
   │                       │                      │
   │                       │                      ├──► StreamFakeFileAsync()
   │                       │                      └──► LogRequest()
   │                       │                      │
   │◄── Response ──────────│◄─────────────────────┘
```

| 404 | Not Found | Несуществующий ресурс |
| 500 | Internal Server Error | Внутренняя ошибка |
